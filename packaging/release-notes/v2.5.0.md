## What's new in 2.5.0

Ready for GTA VI, which comes out on November 19 at 30 FPS on every console.

**Veyra 2.1.9 inside.** Glide now includes everything from Veyra 2.1.9 (released by Likely7 on November 15):

- **AMD FRC frame generation** (2×) on AMD graphics, using the frame interpolation built into the AMD driver
  (AMF). Nothing extra to install: the runtime comes with your AMD driver.
- **FSR 4 ML on Radeon RX 9000** is now preferred for new settings, and falls back to FSR 3.1 with a notice
  when it isn't available.
- **Local audio monitoring separate from recording.** Turn off *Local audio monitoring* in the capture card
  window to stop hearing the console on the PC while recordings and instant replays still get the game sound.
  The old *Don't monitor audio* is now called *No audio input*.
- **NVIDIA G-SYNC profile check and repair** for Glide, with a backup before anything changes.
- **Two graphics cards:** choose the card Glide processes on (*Settings → Performance*), with a warning when
  every frame has to be copied between cards.
- **Editable exclusion regions:** show region outlines and drag regions in Professional mode.
- Windows on other virtual desktops can be captured; a hang with XeSS after resizing a captured window is fixed.

**Plug and play.** Two new switches in the quick setup: *Connect on start* opens your last capture card (with
its settings) or stream when Glide starts, and *Fullscreen on connect* goes fullscreen when the picture
appears.

**Lower delay with 120 Hz.** If your capture card takes 120 Hz (for example the Elgato 4K X, 4K S or HD60 X at
1080p or 1440p), set your PlayStation or Xbox to 120 Hz: each frame reaches the PC about 8 ms sooner, and 40 FPS
games in a 120 Hz mode work too. The quick setup now says so.

**Measure total delay.** A new guide next to the latency switch: film the capture card's passthrough screen and
Glide side by side in slow motion with your phone, count the frames between them, and Glide works out the
delay.

**Always on top** in *Settings → Startup & window*, to keep Glide above a guide or a chat window.

**Also:** the build badge on GitHub no longer turns red when a release build and a normal build run at the same
time. Veyra's new startup intro and music are not used in Glide, which keeps its own look.

**Tested:** built and tested by GitHub Actions on Windows Server without a graphics card: unit tests (including
Veyra's new G-SYNC profile tests), GPU tests on Microsoft's WARP renderer, interface tests, the full install and
start of the app, screenshots of every main page, and the OBS plugin loaded into OBS Studio. AMD FRC, FSR 4 ML,
G-SYNC profiles, two graphics cards and 120 Hz capture have not been tested by us on real hardware in this build;
Veyra's own notes list what Likely7 tested. Please report anything that doesn't work.
