## What's new in 2.9.0

**Go live from Glide.** Stream the boosted picture, frame generation and sound included, straight to Twitch,
YouTube, Kick, TikTok, Facebook Live, Trovo or any RTMP/RTMPS server, without OBS. Add up to eight outputs and
stream to several platforms at once: one encode feeds them all, so a second platform costs upload bandwidth, not
graphics card time. Server lists and recommended limits come from OBS Studio; the bitrate follows the strictest
platform you stream to. Stream keys are encrypted for your Windows user, never shown again and never written to
logs. Each output reconnects on its own when the connection drops, and the dialog shows each one's state,
bitrate, dropped frames and reconnects. Open it with **Go live** in the quick setup.

**Optimise for my PC, rebuilt.**
- Tests every frame generation method your PC can run (DLSS, NVIDIA VFG, ANR, FSR 4/3.1, XeSS, AMD FRC), not
  just the first few, and lists the ones it skipped with the reason.
- Choose a goal: **Balanced**, **Lowest latency**, **Smoothest** or **Best picture**.
- Targets your monitor's own rate on 144, 165 and 240 Hz screens when the game divides into it evenly.
- Reports PC processing latency, its 95th percentile and frame-time jitter for every combination.

**Live HUD Lock tells you what it does.** The quick setup now says whether HUD Lock is running, waiting for
frame generation, or can't run with the current method (XeSS).

**Frame Pacing Repair, hardened.** Clock jumps and stalls restart the fit without reordering frames; a fuzz test
of 400 random sequences now runs in CI.

**Safer ANR install.** *Install from download* lists the archive before unpacking, refuses unsafe paths, links
and unexpected file types, installs into a new folder and swaps it in (the old one comes back if anything fails),
and shows the archive's SHA-256.

**Linux and macOS (preview).** A separate, smaller Glide with its own frame generation, Frame Pacing Repair
and Live HUD Lock on Vulkan, OpenGL or Metal: no NVIDIA, AMD or Intel components needed. Linux as an AppImage or
`.tar.gz`, macOS as one app for Apple Silicon and Intel. Recording and going live are Windows-only for now.

**Portable and checkable.** Every release now carries `SHA256SUMS.txt` and a list of the exact pinned components.
`Install-Glide.cmd -InstallDir <folder> -NoShortcuts` keeps Glide and its settings in one folder.

**Tested how.** Windows: built, unit and GPU (WARP) tests, QML tests, install and start test, and the going-live
tests against a local RTMP and RTMPS server (connect, send, server restart and reconnect, key never in logs), all
in CI. Not yet tested by a person streaming to the real platforms with a capture card: reports are welcome.
Linux/macOS: core tests with sanitizers, self-tests at 60 and 120 FPS, a GPU check (the generated frame
matches the processor reference at 67-69 dB on OpenGL and Metal) and a clean Ubuntu container, in CI; not yet
tested on a person's machine with a capture card.
