## What's new in 2.9.2

**NVIDIA optical flow is built in.** On NVIDIA RTX graphics cards, Glide can now use NVIDIA's own optical flow
for motion estimation, as Veyra does, instead of AMD FidelityFX optical flow. Its two interface headers come from
a private build secret: no NVIDIA SDK file is in the repository or the download. Other graphics cards keep using
AMD FidelityFX optical flow, and NVIDIA Video Frame Generation is unchanged (it has its own optical flow).

Also includes everything in 2.9.1: the PS5 pairing fix and the full going-live upload note.

**Tested how.** Built with NVIDIA optical flow, unit tests, QML tests, going-live tests and the install test, in CI
on Windows (no NVIDIA graphics card there). Not yet tested on an RTX card: reports are welcome.

**Credits.** Glide is built on [Veyra](https://github.com/Likely7/Veyra-NRVideo) by Likely7. ANR frame
generation is by [Apex Compute](https://apexcompute.com).
