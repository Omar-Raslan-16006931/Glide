## What's new in 2.9.1

**Fix: PS5 pairing lost the Account ID.** In *PS5 streaming*, typing the Account ID (or the console's address)
and clicking *Pair and save* straight away didn't save what you typed: pairing failed and the fields emptied.
Both fields now save as you type. Thanks to the Reddit user who reported it.

This is also what *PS5 controller control* needs: pair once in *PS5 streaming*, then turn it on in the capture
card settings to play with any controller Windows sees (Xbox, Switch Pro, 8BitDo...) while the picture comes from
your capture card.

**Fix: the going-live upload note was cut off.** The note with the upload bandwidth you need is now shown in
full.

**Tested how.** Built, unit tests, QML tests (including a new test that types the Account ID and clicks *Pair and
save*), the going-live tests and the install test, in CI on Windows. Pairing with a real PS5 has not been
re-tested by us since the fix; the change only affects how the two fields save their text.
