## What's new in 2.4.0

**No capture card? Stream instead.** Glide now includes Veyra's three streaming sources, with the same frame
generation, AI enhancement, HUD protection and recording as a capture card:

- **PS5 streaming:** your own PS5 over your home network (Remote Play, via chiaki-ng). Pair once with your PSN
  account ID and the PIN the PS5 shows; your controller works through Glide.
- **PC streaming:** another computer running Sunshine (Moonlight protocol). Pair once with a PIN.
- **Xbox streaming** (experimental, unofficial): your own Xbox, after a Microsoft account sign-in.

**Quick setup tools as cards.** Optimise for my PC, Game presets, HUD protection and Comparison clip are now
cards with a line on what each does, and the comparison clip card says why it is unavailable (no picture,
or a recording running).

**OBS plugin 1.2.0.** Looks for the Glide window more efficiently (one window check instead of a full scan
every 1.5 seconds on OBS's graphics thread), and *Tools → Open Glide* uses the Glide location set in a
Glide source.

**Also:** the theme row in *Settings → Appearance* is now called *Theme*; screenshots in the README are new.

**Licences.** The streaming libraries are compiled from pinned sources (chiaki-ng with Veyra's reviewed patches,
AGPL-3.0 with the OpenSSL exception; moonlight-common-c, GPL-3.0; libdatachannel, MPL-2.0; and static OpenSSL,
Opus, SDL3 and others from vcpkg). Their exact source is attached as the *streaming-source* archive.

**Tested:** built and tested by GitHub Actions on Windows Server without a graphics card or network devices:
unit tests, GPU tests on Microsoft's WARP renderer, interface tests, the full install and start of the app,
screenshots of every main page and the three streaming dialogs, and the OBS plugin loaded into OBS Studio.
Streaming to a real PS5, Sunshine PC or Xbox, and use with a capture card and a real graphics card, have not
been tested by us in this build; please report anything that doesn't work.
