## What's new in 2.4.1

**New icon.** The Glide icon now has the same arrows as the full logo: the first arrow ends in the logo's
swoosh point and the second has its bevelled ends, in the logo's green. You'll see it on the program, the
Start menu and desktop shortcuts, the taskbar, Alt+Tab, the top bar and home screen of the app, and the About
page.

**Icons refresh after updating.** Windows keeps old icons in a cache, so after an update the shortcuts
could keep showing the previous icon. The installer now asks Windows to refresh it. A taskbar pin made
before the update can still show the old icon until you sign out and back in, or unpin and pin Glide again.

**Website.** Glide has a website with downloads, install steps, requirements, FAQ, credits and licensing:
https://dosukasol.github.io/Glide/

Nothing else changed since 2.4.0: same features, settings and runtime. To update, run the new installer;
your settings are kept.

**Tested:** built and tested by GitHub Actions on Windows Server without a graphics card: unit tests, GPU
tests on Microsoft's WARP renderer, interface tests, the full install and start of the app, screenshots of
every main page, and the OBS plugin loaded into OBS Studio. The new icon on a real Windows 11 desktop and
taskbar has not been checked by us; please report anything that looks wrong.
